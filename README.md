# Titanic Survival Prediction

Machine Learning project that predicts passenger survival on the Titanic dataset using Python and Scikit-Learn.

## Project Objectives
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training and Evaluation
- Survival Prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Prediction

## Results
Built a classification model to predict passenger survival based on demographic and travel-related features.
